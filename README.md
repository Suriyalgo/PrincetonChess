# Princeton Chess Club Website

A static, animation-rich website for the Princeton University Chess Club.

## Pages
- `index.html` — Home: animated hero, stats counters, marquee, about/mission
- `events.html` — Events & recurring schedule
- `team.html` — Officers (3D tilt cards)
- `members.html` — Members & ladder leaderboard
- `join.html` — Sign-up form, mailing list, socials

## Shared files
- `styles.css` — Princeton orange/black theme, animations
- `script.js` — custom chess-piece cursor, scroll reveals, counters, tilt/magnetic effects

## Running locally
Just open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

No build step or dependencies — plain HTML/CSS/JS.
